# Use cases

Each page here is one thing a network sells or runs, explained step by step, with a complete config you can read and copy. Every config on these pages is checked by Circuit's tests, so it validates as shown.

| Use case                                                     | What you sell or run                                                                         |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| [Selling IP transit](/use-cases/ip-transit)                  | The whole internet, to a customer with its own AS                                            |
| [Selling IX-only transit](/use-cases/ix-transit)             | Only the routes you learn at internet exchanges, often sold as "content" or domestic transit |
| [Running an internet exchange](/use-cases/internet-exchange) | A peering LAN where members connect to each other                                            |

Patterns are where a project starts; use cases are what you add to it. The two transit pages build on [an edge router](/patterns/edge-router).
