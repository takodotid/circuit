# Patterns

How to lay out a network's repository, from one router at home to a colocation provider with tenants. Each is a starting point; take what fits.

| Pattern                                         | For                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------ |
| [A single site](/patterns/single-site)          | A homelab, an office or an internal network: a router and a switch |
| [An edge router](/patterns/edge-router)         | Your own AS, with transits and internet exchanges                  |
| [Colocation with tenants](/patterns/colocation) | A provider whose customers each get their own networks             |
