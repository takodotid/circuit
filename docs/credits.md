- [Bun](https://bun.sh), which runs Circuit, and [TypeScript](https://www.typescriptlang.org), which checks every name in a config.
- [ssh2](https://github.com/mscdex/ssh2), every session to a device.
- [VitePress](https://vitepress.dev), this site.

## Shaped by

- The [NLNOG Ring looking glass](https://github.com/NLNOG/lg.ring.nlnog.net) community format, which `circuit communities` prints.
- [PeeringDB](https://www.peeringdb.com) and [RIPEstat](https://stat.ripe.net), whose APIs `circuit peeringdb` and `circuit refresh` read.
- RFC 5798 for VRRP, RFC 8195 for large communities, RFC 8210 for RPKI to router, and RFC 9234 for BGP roles.
