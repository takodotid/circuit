# Intermediate entry check

Intermediate connects networks to each other and to the internet, and every lesson in it builds on what Elementary teaches: VLANs, trunks, DHCP, NAT, firewalls, management and writing a network down in Circuit. This check makes sure those are in place first.

Passing it opens Elementary as well, since it asks about Elementary itself. If some of it is new to you, start with [Elementary](/academy/#elementary) instead.
