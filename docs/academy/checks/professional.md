# Professional entry check

Professional is about running a provider network: what is sold, the hardware, routing at scale, the security of routing and day-to-day operations. Every lesson in it builds on what Intermediate teaches: routing tables, IPv6, OSPF, autonomous systems, BGP and its policies, and LAGs and spanning tree. This check makes sure those are in place first.

Passing it opens the levels before it as well. If some of it is new to you, start with [Intermediate](/academy/#intermediate) instead.
