# Elementary entry check

Elementary builds a small network and writes it down in Circuit, and every lesson in it uses what Beginner teaches: packets, addresses, bits, switches, routers, DNS and ports. This check makes sure you know those before you start.

If networking is new to you, start with [Beginner](/academy/#beginner) instead. If you already know it, this takes a few minutes.
