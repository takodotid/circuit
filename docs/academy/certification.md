# Certification

::: info Coming soon
The certification is not open yet. This plan may change before it opens.
:::

The lessons teach you to build a network, and the certification asks you to show it. You get a network someone needs, and you write it in Circuit. The Tako Network Engineering Team, who maintain Circuit, review your work.

<img class="academy-art" src="/illustrations/academy/certificate.webp" alt="" width="1100" height="708" loading="lazy" />

## How it works

1. **You ask for a case.** The certification is given only on request, because a person reviews each case.
2. **You get a case.** It describes a network the way a customer would: its sites, devices, VLANs, addresses, and what must be kept apart.
3. **You write it in Circuit.** You write one file per device, and checks of your own, until `circuit validate` passes and the plan matches the case.
4. **Your work is reviewed.** Reviewers read your files and plans, and may ask you to explain a choice.
5. **You get a certificate.** Anyone can check its ID on the [graduates page](/academy/graduates), and you are listed there if you want to be.

## Getting ready

The case uses the lessons up to the Intermediate level. If you can do the projects [a single site](/academy/elementary/project-single-site) and [an edge router](/academy/intermediate/project-edge-router), you are ready.

Whether the certification is free or paid, and when it opens, is not decided yet. This page says both before anyone can apply.
