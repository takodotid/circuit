# Certification

::: info Coming soon
The certification is not open yet. This page describes how it is planned to work, and will change before it opens.
:::

The lessons teach you to build a network. The certification asks you to show it: you are given a network to provision, you write it down in Circuit, and the result is reviewed by the Tako Network Engineering Team, who maintain Circuit.

<img class="academy-art" src="/illustrations/academy/certificate.webp" alt="" width="1100" height="708" loading="lazy" />

## How it will work

1. **You ask for a case.** The certification is given on request, so each case is reviewed by a person.
2. **You get a case to solve.** A short description of a network someone needs: its sites, devices, VLANs, addresses and what must be kept apart, the way a real customer would describe it.
3. **You write it down in Circuit.** One file per device, with checks of your own, until `circuit validate` passes and the plan is what the case asks for.
4. **Your work is reviewed.** Reviewers read your files and your plans, and may ask you to explain a choice.
5. **You get a certificate.** With an ID anyone can check on the [graduates page](/academy/graduates), where you are listed if you want to be.

## Getting ready

The case uses what the lessons teach, up to the Intermediate level. If you can do the two projects, [a single site](/academy/elementary/project-single-site) and [an edge router](/academy/intermediate/project-edge-router), you are ready.

Whether the certification is free or paid, and when it opens, is not decided yet. Both will be on this page before anyone is asked to apply.
