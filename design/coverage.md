# Circuit v1 feature coverage

Every feature an engineer configures on the five platforms, and what Circuit v1's model ([the model](../docs/reference/model.md), `src/config/`) and Circuit 0.43's renderers have. Researched 2026-11-01 from vendor documentation; sources at the end.

| Key                      | Meaning                                                                                                                                   |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| yes                      | Configurable on at least one hardware family of the platform. A note names the family or release when it is limited (`MX only`, `7.22+`). |
| partial                  | Only part of the feature, or only through another box (`via FortiSwitch`). The note says what is missing.                                 |
| no                       | The platform does not have it.                                                                                                            |
| unknown                  | Not confirmed either way in the vendor's documentation.                                                                                   |
| n/a                      | Not a device feature (Circuit's own bookkeeping, or apply mechanics).                                                                     |
| In v1 model              | yes: the model has the field. partial: some of it.                                                                                        |
| In Circuit 0.43 renderer | yes: rendered on every platform that has the feature. partial: rendered only on the platforms listed (ROS, JUN, VRP, FOS, RCM).           |

Scope: RouterOS 7.25 stable (7.26 manual, CCR and CRS); Junos OS on QFX, MX, EX, SRX; VRP on CloudEngine CE data-centre switches and NetEngine NE40E/NE8000 (not CloudEngine S or AR); FortiOS 7.x on FortiGate; Raisecom ROS from the RAX721 P200R003 guide and ISCOM2600G/RAX711 guides, not ROS 6.5.2 on the RAX721-C-6C48 itself.

## Caveats

- Raisecom: 167 rows are unknown; the public guides do not cover ROS 6.5.2 on the RAX721-C-6C48. Some yes rows rest only on the datasheet's RFC list (4-byte ASN, confederation, BGP VPLS, MSDP, NETCONF, 6PE).
- VRP: support.huawei.com pages render with JavaScript, so most rows were confirmed from search snippets of Huawei's own pages, or from well-known commands.
- Firewall rows on VRP and Raisecom: no stateful firewall; matches a stateless ACL covers are marked with that note. NAT and IPsec on VRP need an NE service board.
- RouterOS: ASPA and the CMR central manager are 7.26 beta only and counted as no.
